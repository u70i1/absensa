# Dokumentasi Absensa

Absensa membantu sekolah mencatat kehadiran siswa, mengelola data siswa dan kelas,
serta mengirim pemberitahuan ketidakhadiran kepada orang tua atau wali melalui
WhatsApp. Setelah dipasang pada komputer server sekolah, aplikasi dibuka melalui
browser di jaringan sekolah.

## Mulai dari kebutuhan Anda

| Kebutuhan | Langkah berikutnya |
| --- | --- |
| Sekolah belum memasang Absensa | Baca [panduan pemasangan](memulai/instalasi.md) atau gunakan bantuan pemasangan di bawah. |
| Guru akan mencatat presensi | Minta alamat aplikasi, akun operator, dan perangkat presensi kepada pengelola sekolah. |
| Tata usaha akan menyiapkan data sekolah | Minta akun administrator kepada petugas yang memasang aplikasi. |
| Ingin mencari panduan berdasarkan tugas | Buka [bagian Memulai](memulai/index.md). |

## Bantuan pemasangan untuk sekolah

Kirim permintaan ke [kontakabsensa@gmail.com](mailto:kontakabsensa@gmail.com)
dengan subjek **Permintaan Pemasangan Absensa**. Sertakan nama sekolah,
kota/kabupaten, kontak penanggung jawab, dan keterangan komputer yang tersedia.
Jika belum mengetahui spesifikasinya, cukup jelaskan kondisi sekolah.

## Ketersediaan panduan

[Panduan pemasangan](memulai/instalasi.md) sudah tersedia. Panduan penggunaan
untuk operator, administrator, dan referensi fitur masih dalam penyusunan;
halaman yang belum selesai menampilkan keterangan tersebut.

Petugas IT dapat membaca
[panduan teknis pemasangan dan pemeliharaan](https://github.com/u70i1/absensa/blob/main/deploy/README.md).
Untuk menyimpan cadangan ke USB atau disk eksternal, gunakan
[panduan cadangan untuk petugas sekolah](https://github.com/u70i1/absensa/blob/main/deploy/PANDUAN-CADANGAN.md).
