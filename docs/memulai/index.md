# Memulai

Pilih panduan sesuai tugas Anda. **Guru dan petugas presensi tidak perlu
memasang aplikasi pada setiap perangkat**; gunakan alamat aplikasi yang
diberikan pengelola sekolah.

## Sekolah belum memasang Absensa

Mulai dari [Memasang Absensa](instalasi.md). Pemasangan dilakukan oleh petugas IT
pada komputer server sekolah. Jika membutuhkan bantuan, kirim permintaan ke
[kontakabsensa@gmail.com](mailto:kontakabsensa@gmail.com).

## Panduan sesuai tugas

| Tugas Anda | Panduan | Status |
| --- | --- | --- |
| Mencatat presensi harian | [Panduan operator](operator/index.md) | Sedang disusun |
| Mengelola data siswa, kelas, dan akses | [Panduan administrator](administrator/index.md) | Sedang disusun |
| Menangani kendala penggunaan | [Pemecahan masalah](pemecahan-masalah.md) | Sedang disusun |

Selama panduan penggunaan disusun, hubungi pengelola aplikasi di sekolah untuk
memperoleh alamat aplikasi, akun, dan petunjuk penggunaan setempat.
