Panduan mengimpor data
  1. Unduh template Siswa atau Kelas, atau gunakan file hasil ekspor. Unggah satu file .xlsx dengan maksimal 10.000 baris data.
  2. Pertahankan nama sheet (students atau classes), judul kolom, dan urutannya. Sheet “Tentang Ekspor” tidak diimpor.
  3. Untuk mengedit, pertahankan ID yang sudah ada. Untuk membuat siswa atau kelas baru, kosongkan ID. Baris kosong diabaikan.
  4. NISN harus tepat 10 digit dan disimpan sebagai teks. Pilih STATUS Aktif atau Tidak aktif. ID KELAS siswa harus sudah terdaftar, atau kosong jika belum memiliki kelas.
  5. NOMOR WALI boleh kosong; jika diisi, gunakan angka saja, diawali 08 atau 628. JENJANG kelas: 1–20; NAMA KELAS: maksimal 20 karakter.
  6. Gunakan nilai langsung, bukan rumus. Periksa ringkasan dan kesalahan, batalkan baris yang tidak diinginkan, lalu pilih Simpan Perubahan. Baris bermasalah tidak disimpan. Pratinjau berlaku selama satu jam.
