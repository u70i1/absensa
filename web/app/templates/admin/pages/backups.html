Simpan salinan di flashdisk

Cadangan otomatis tersimpan di komputer sekolah. Simpan salinan di flashdisk atau hard disk eksternal agar data tetap aman jika komputer rusak.

  1. Pilih Unduh pada cadangan yang berhasil.
  2. Salin file unduhan ke flashdisk atau hard disk eksternal.
  3. Cabut perangkat dan simpan di tempat aman.

Lakukan secara rutin, misalnya setiap akhir minggu. File tetap dilindungi kunci keamanan.

Simpan kunci keamanan di tempat aman yang berbeda dari flashdisk. Jika perlu memulihkan data, minta bantuan petugas teknis sekolah.
